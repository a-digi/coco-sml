# Small Model Language (SML)

A minimalistic modeling language implemented in pure Go.

## Overview
Small Model Language (SML) is a lightweight, expressive language designed for modeling and simulation tasks. The project is written entirely in Go, focusing on simplicity, performance, and ease of integration.

## Features
- Pure Go implementation (no external dependencies)
- Simple syntax for defining models
- Extensible and easy to embed in Go projects
- Fast parsing and execution

## Getting Started

### Prerequisites
- Go 1.20 or newer

### Installation
Clone the repository:
```sh
git clone <your-repo-url>
cd coco-sml
```

Build the project:
```sh
go build ./...
```
